# 🚀 TaskFlow Pro — Modern To-Do & Task Management

A beautiful, single-file, modern To-Do List application built with pure HTML, CSS, and Vanilla JavaScript. Designed for high productivity, aesthetic excellence, and zero-configuration deployment.

## ✨ Features

- 🎨 **Glassmorphism & Modern UI**: Sleek dark and light mode toggle with smooth glassmorphism effects, CSS variables, and modern typography (`Plus Jakarta Sans` & `Outfit`).
- 📊 **Real-time Analytics Dashboard**: Dynamic task completion progress bar, active counters, and completion rate calculations.
- ⚡ **Full CRUD Capabilities**: Add, edit, complete, star/favorite, and delete tasks.
- 🏷️ **Categorization & Priorities**: Group tasks by categories (*Work, Personal, Study, Health, Finance*) and priorities (*High, Medium, Low*).
- 📅 **Due Dates & Overdue Alerts**: Set deadlines with visual overdue status indicators.
- 🔍 **Instant Search & Filters**: Search across titles, descriptions, and categories. Filter by *All, Active, Completed, Starred*.
- 🔃 **Flexible Sorting**: Sort tasks by Newest, Oldest, Due Date, or Priority level.
- 💾 **LocalStorage Persistence**: Automatic saving to browser local storage. Pre-seeded sample tasks on first launch.
- 📥 **Export Backup**: Export tasks as JSON backups anytime.
- 📱 **Fully Responsive**: Flawless layout across Desktop, Tablet, and Mobile screens.
- 📦 **Single-File Deployment**: All HTML, CSS styling, and JavaScript logic are bundled inside `index.html` for instant deployment.

## 🛠️ How to Run & Deploy

### Option 1: Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/MadihaSehar/Learning-Javascript-From-Scratch.git
   ```
2. Double-click `index.html` to open it in any web browser!

### Option 2: Deploy to GitHub Pages
1. Go to your repository settings on GitHub.
2. Under **Pages**, set the Source branch to `main` (or `master`) and folder to `/ (root)`.
3. Click **Save**. Your site will be live within a minute!

## 💻 Tech Stack

- **HTML5**: Semantic tags, accessible structure.
- **Vanilla CSS3**: CSS custom properties, backdrop filters, glassmorphism, flexbox/grid layout, smooth keyframe animations.
- **Vanilla JavaScript (ES6+)**: Event delegation, LocalStorage API, state management, modal logic, dynamic rendering.
- **Lucide Icons**: SVG icon library loaded via CDN.
